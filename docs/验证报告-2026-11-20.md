### P1-1 notify 内部令牌占位符漏 `SP_INTERNAL_TOKEN`（生产环境必现）

`smart-parking-notify/.../NotificationController.java:43`

```java
@Value("${smart-parking.internal-token:SmartParking-Internal-2026}")
private String internalToken;
```

与本月刚修掉的 payment 同类问题：README 指导运维用 `SP_INTERNAL_TOKEN` 注入令牌，但此处只读 `smart-parking.internal-token`。一旦只设环境变量：

- 网关校验读到**新令牌** → 放行；
- notify 广播拉业主列表时仍发**旧默认令牌** → 内部接口 403；
- 结果：**广播通知静默失败**（`fetchOwnerIds` 拿不到人，公告发不出去），日志只有一条失败记录。

修复（1 行）：

```java
@Value("${SP_INTERNAL_TOKEN:${smart-parking.internal-token:SmartParking-Internal-2026}}")
```

同时建议把 `Constants.DEFAULT_INTERNAL_TOKEN` 作为默认值，避免第三处字面量。

### P1-2 道闸签名盐硬编码，厂商替换被阻塞

`GateSigner.java:15`：`private static final String SALT = "SmartParkingGateSandbox";`

- 接真实厂商要么改这一行代码，要么让厂商接受自创算法；
- 该盐未纳入 `strict-secrets` 校验，生产忘改也能启动；
- 验签用 `String.equals`，非恒定时间比较（沙箱可接受，真实通道建议换 `MessageDigest.isEqual`）。

建议：改为 `smart-parking.device.gate-sign-salt`（`SP_GATE_SIGN_SALT`），默认保留现值并纳入 strict 校验，约 30 行 + 2 例单测。
