## 〇、共享前缀（每个页面生成前必须粘贴这段）

````text
【角色】你是资深 Vue3 前端工程师，负责「智慧星河 SmartGalaxy」小区智慧停车管理系统管理端开发。
【技术栈】Vue 3.4 + Vite + <script setup> 组合式 API + Element Plus + Pinia + Vue Router + Axios。
【设计系统】项目已有全局 tokens.css（--sp-* 变量），必须引用以下变量，禁止自创色值/字号/间距：
- 背景 var(--sp-bg) #0B0A16；卡片用 .sp-card（毛玻璃+边框）；页面容器 .sp-page（max-width 1360px）
- 主色 var(--sp-brand) #7C8DB5；点缀 var(--sp-teal) #7BC8B0；焦点色(全站唯一高亮) var(--sp-gold) #F0C987；危险 var(--sp-danger) #D98C8C；警告 var(--sp-warning)
- 文字 var(--sp-text) / var(--sp-text-2) / var(--sp-text-3)；数字等宽 .sp-num
- 圆角：卡片 var(--sp-radius-card)=16px / 按钮 12px / 标签 8px / 胶囊 999px
- 动效：微交互 var(--sp-dur-micro)=150ms / 组件 250ms / 页面 400ms，缓动 var(--sp-ease)
- 图表色板 var(--sp-chart-1..5)，网格线 var(--sp-chart-grid)
【通用要求】
- 输出完整可运行 Vue3 SFC（<script setup>），Element Plus 组件按需 import
- 图标一律用 @element-plus/icons-vue，禁止 emoji 当图标
- 每个页面必做四态：loading（星仔旋转）/ empty（星仔插画）/ error（温和提示+重试）/ success（星光反馈）
- 状态标签用对应状态色；表格数字对齐用 .sp-num；敏感信息脱敏（手机号 138****1234）
- 禁止：高饱和霓虹色、纯白刺眼文字、页面间风格漂移、省略四态
【输出格式】只输出一个 .vue 文件，文件头注释写明建议存放路径（src/views/...）。
````

````text
- 车辆：我的车辆列表（车牌/颜色/品牌/绑定时间），添加车辆；邀请访客：生成邀请码卡片（复制/分享）
- 订单：停车记录列表（时间线样式），进行中订单高亮；点击详情可在线缴费（微信/支付宝）
- 我的：个人信息（手机脱敏）、通知列表、设置、退出登录
- 四态：加载 loading（星仔旋转）；空状态（星仔场景插画）；支付失败 error；成功 success
- 接口：同管理端 API（/api/parking/available、/api/order/current、/api/order/calculate、/api/payment/create 等）
````

## 十六、API 封装与路由（工程骨架）

````text

4. src/store/user.js（Pinia）：state{ token, userInfo, roles }，actions{ login, fetchInfo, logout }，token 持久化 localStorage
````

## 附录 B：一键生成全站（Mega-Prompt 顺序）

若想用一个会话连续生成全站，按以下顺序逐条粘贴（每轮先粘贴「〇、共享前缀」再粘贴对应需求）：

1. **工程骨架**（十六：request/router/store/api）→ 2. **公共组件**（十五：MetricCard/StatusTag/EmptyState/StarLoading）→ 3. **主布局**（一）→ 4. **登录页**（二）→ 5. **数据看板**（三）→ 6. **车位管理**（四）→ 7. **车辆管理**（五）→ 8. **订单管理**（六）→ 9. **缴费管理**（七）→ 10. **设备管理**（八）→ 11. **用户管理**（九）→ 12. **数据统计**（十）→ 13. **通知中心**（十一）→ 14. **异常页**（十二）

生成顺序原则：**先地基（骨架+公共组件）→ 再外壳（布局）→ 最后业务页**，这样每个业务页都能引用已生成的公共组件，风格天然一致。
