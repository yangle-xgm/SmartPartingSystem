## 一、探照灯效果 · 重写技术方案（三层光照模型）

### 1.1 设计目标（必须是可感知的效果，不是形容词）

- 鼠标移动时，一束暖光"扫过"星空背景，**光到之处**：星星粒子点亮、标题文字发光发亮、元素微亮；
- **光未到之处**保持深邃，但保留 25%~35% 的基础可见度——避免 V4.0 的"全黑挖洞感"；
- 桌面端持续 60fps；移动端自动漫游光束，绝不留白。

### 1.2 三层光照模型（替代 V4.0 的单层遮罩）

| 层 | 名称 | 实现方式 | 作用 |
|----|------|---------|------|
| L0 | 氛围光 | 静态 CSS 多层 `radial-gradient`（左上深空、左下极光青、右下星光金，opacity 0.07~0.09） | 页面四角基础光晕，避免死黑 |
| L1 | 探照灯光 | Canvas 径向渐变 + `globalCompositeOperation='lighter'` 加亮合成，跟随鼠标 lerp 缓动 | 主光照，被照区域**变亮** |
| L2 | 响应层 | JS 每帧计算文字中心到光斑的距离 → 实时改写 `text-shadow` / `filter: brightness` | 文字/元素"感光"，这是高级感的关键 |

### 1.3 技术要点清单（可直接照抄的实现参数）

1. **加亮不压暗**：光照层用 `screen` / Canvas `lighter` 混合，**禁止** `multiply`（深色背景压暗 = 全黑）。
2. **光斑结构**（半径 540px）：中心 `rgba(255,252,245,0.10)` → 中环暖金 `rgba(240,201,135,0.07)` → 外缘极光青 `rgba(123,200,176,0.035)` → 70% 处完全透明；外圈再叠一层 950px 的低透明辉光。
3. **磁吸延迟**：`pos += (target - pos) * 0.08` 每帧缓动，形成"灯光被拖住"的磁吸感。
4. **文字感光**：每帧计算每个字中心到光斑距离 `d`，强度 `i = clamp(1 - d/280, 0, 1)`；`text-shadow` 半径 `18 → 64px`、光晕 alpha `0.12 → 0.52`、`brightness 1 → 1.3`，逐字随距离平滑变化。
5. **光尘粒子**：远景 130 颗小星（慢、暗、半径 ≤1.5px）+ 近景 38 颗光尘（大、亮）；粒子距光斑 < 280px 才点亮，550px 处渐隐——形成"灯光扫过尘埃"的流动感。
6. **自定义光标**：8px 金色实心点（含光晕）+ 34px 圆环（二次 lerp，弹簧跟随）；悬停按钮时圆环放大至 54px、变极光青。
7. **流星**：每 6~12s 随机一颗，Web Animations API 斜向划过，-25° 角度。
8. **性能红线**：单 Canvas 绘制全部粒子与光照；粒子总数 ≤ 170；**禁止**每帧 `shadowBlur`（光晕用预置渐变或叠加圆形替代）。
9. **移动端（hover:none）**：隐藏自定义光标；光束沿对角线自动漫游（正弦周期 12s）；触摸时跟随手指，4s 无触摸恢复漫游。

### 1.4 禁止清单（防 AI 工具跑偏，直接粘给工具）

```
禁止：
- mix-blend-mode: multiply 做光照遮罩
- cursor: none 而不提供自定义光标
- 移动端直接 display:none 关闭特效（必须给自动漫游兜底）
- 每帧调用 shadowBlur，或粒子超过 200 颗
- 纯白文字、高饱和霓虹色（#6366F1/#06D6A0 等）
- 用 emoji 代替图标（统一 SVG 线性图标）
- 页面之间风格漂移（必须复用同一套 Tokens）
```

## 二、设计系统 Design Tokens（V5.0 定稿 · 全站唯一版本）

> 使用规则：**所有页面、所有组件只允许使用下表的值，禁止自创色值/字号/间距。**

## 七、Vue3 落地适配（smart-parking-web）

> 本系统前端为 **Vue 3.4 + Vite + Element Plus + Pinia + Vue Router**，V5.0 已按此技术栈落地，见同目录 `vue3/` 文件夹。

| 文件 | 说明 |
|------|------|
| `vue3/src/styles/tokens.css` | 全站 Design Tokens（CSS 变量 `--sp-*`），main.js 引入后全局可用；含 Element Plus 深色模式覆盖 |
| `vue3/src/views/login/LoginView.vue` | 探照灯登录页 SFC（`<script setup>` + 组合式 API），含完整光照引擎与卸载清理 |
| `vue3/README.md` | 三步接入指南（引入 tokens → 注册路由 → 改跳转）+ 常见问题 |

**Vue3 落地要点**：

1. 所有页面的颜色 / 圆角 / 间距 / 动效一律引用 `var(--sp-*)`，**禁止在组件里写死色值字号**——这是多页面一致性的根基。
2. 探照灯引擎在 `onUnmounted` 中清理 rAF、事件监听与定时器，避免路由切换后泄漏。
3. 登录页用 `position: fixed` 全屏，建议作为独立路由，不套管理端 Layout。
4. Element Plus 组件自动继承主题：引入 `element-plus/theme-chalk/dark/css-vars.css` 并在 `<html>` 加 `class="dark"`（tokens.css 已写好覆盖）。
5. 生成其他页面时，把「四、页面生成模板」粘贴给 AI 工具，并要求输出 `var(--sp-*)` 变量引用。

## 八、去 AI 味 · 文案与视觉收敛规范（V5.2 新增）

> 背景：V5.1 页面被反馈"AI 味太重"——宣传册式大词、促销腔、英文装饰、符号过密、模板感强。**保留**品牌名「智慧星河」、Slogan「让每一次停泊，都有星光指引」、探照灯光感、星仔 IP；**去掉**下面三类 AI 味。

### 8.1 文案禁令（全站生效）

| 类型 | 禁例（出现即改） | 改为（平实、具体、有对象） |
|------|----------------|--------------------------|
| 大词空泛 | 全流程数字化运营 / 一应俱全 / 一站式 / 赋能 | 直接说功能：覆盖找位、进出、计费、设备 |
| 促销腔尾句 | 业主找位不再绕圈 / 出入场零等待 / 在线率一目了然 | 地图实时显示空闲/占用/预约；识别失败转人工确认；设备在线率随时可查 |
| 对仗口号 | 三步完成一次无感停车体验 | 入场识别 → 计费 → 出场，三步走完一次停车 |
| 多余英文 | WELCOME BACK / SMART PARKING ·… | 欢迎回来（品牌名 SMART GALAXY 除外） |
| 叠词标签 | 小区智慧停车管理系统 · 智能停车解决方案 | 小区智慧停车管理系统（一个就够了） |
| 四字词+冒号清单 | 智慧停车 · 四大能力 / 全流程闭环 | 核心功能 / 停车流程 / 功能模块 |
| 符号堆叠 | ✦ ◉ ◈ ● ✧ 大量混用 | 主 CTA 保留 1 个符号，其余去掉 |

### 8.2 视觉收敛原则

1. **一个焦点**：每屏只保留 1 个视觉焦点（Hero 的探照灯 / 星仔点亮），次要光晕、粒子、光标不叠加抢戏。
2. **符号克制**：按钮、标签、标题前的装饰符号全站 ≤ 3 处。
3. **光效降密度**：ambient 氛围光 + canvas 粒子 + 光标光晕 + 卡片光晕不四层同屏；卡片光晕在管理端去掉，保留在品牌页。
4. **管理端与品牌页风格统一**：品牌页负责"讲故事"，管理端负责"干正事"（Element Plus 默认克制风格保留，不做额外光效）。

### 8.4 明暗双主题（V5.3 方案 A · 已落地）

> 用户决策：品牌页（Welcome / Login / Register）保留**深色星光**（答辩开场沉浸感）；**管理端 11 个业务页切换浅色**（长时间使用友好 + 投影清晰 + 弱色文字对比度达标）。

| 范围 | 主题 | 依据 |
|------|------|------|
| Welcome / Login / Register | 深色（`.dark` 容器） | 星空叙事 + 星光金焦点 + 演示开场 |
| Dashboard / 车位 / 车辆 / 订单 / 缴费 / 设备 / 邀请 / 通知 / 审计 / 统计 / 用户 / 预约 | 浅色（`.light` 容器） | 长时盯屏疲劳低、投影仪不脏、对比度达标 |

**实现机制（纯 CSS 变量切换）**：

1. `tokens.css` 保留 `:root` 深色默认值 + 新增 `.light` 分支（重定义全套 `--sp-*` 与 `--el-*`）；
2. `main.js` **移除全局 `html.dark`**；Element Plus 深色覆盖块选择器改为 `html.dark, .dark`；
3. 品牌页根容器加 `dark` class，管理端 Layout 根容器加 `light` class——因组件全部引用 `var(--sp-*)`，**自动切换，业务页零改动**；
4. layout 侧边栏/头部写死深色 `rgba` 改为 `--sp-sidebar-bg / --sp-header-bg / --sp-hover-bg` 变量。

**浅色分支关键值**（对比度 ≥4.5:1 校验）：

| 变量 | 深色（:root） | 浅色（.light） | 浅色对比度 |
|------|-------------|---------------|-----------|
| --sp-bg | #0B0A16 | #F4F6FA | — |
| --sp-card | rgba(255,255,255,.04) | #FFFFFF | — |
| --sp-text | #EDF1F8 | #232838 | ≈17:1 |
| --sp-text-2 | #93A3BF | #5A6577 | ≈7:1 |
| --sp-text-3 | #5C6B8A | #5F6B85 | ≈4.9:1 ✅ |
| --sp-gold | #F0C987 | #B07B24（深金） | ≈4.4:1（焦点文字） |

**验收**：管理端无写死深色 rgba；`rgba(255,255,255,…)` 只在品牌页出现；浅色下 Element Plus 组件（表格/表单/卡片）对比度正常。
